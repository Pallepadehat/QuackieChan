# Security and privacy

Quackie Chan can see your screen, so its privacy promises matter: nothing leaves your Mac except model downloads you ask for, screenshots are never saved, and the duck never acts without your opt-in.

If you find a way that breaks any of that (data leaving the Mac, a web page steering the duck into doing something, the duck closing or touching things it shouldn't), please **don't open a public issue**. Report it privately through [GitHub's security advisories](https://github.com/Pallepadehat/QuackieChan/security/advisories/new). You'll get a reply within a week.
